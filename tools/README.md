# کنترل اسناد

از ریشهٔ همین ریپو اجرا کنید:

```sh
python tools/check_docs.py
```

Python 3.12 و Git کافی‌اند؛ نصب بسته لازم نیست. این کنترل، Git blobهای manifest، مسیر/anchor لینک‌های معمول Markdown جاری، استثناهای تاریخی، دسترس‌پذیری اسناد از ورودی و شمارهٔ تکراری ADR را بررسی می‌کند. همهٔ انواع HTML/reference-link، صحت لینک بیرونی، اعتبار حقوقی استاندارد و رفتار Runtime را اثبات نمی‌کند. workflow همین دستور را اجرا می‌کند.

فایل تاریخی را برای پاس‌شدن لینک تغییر ندهید؛ resolver را با وضعیت درست به‌روز کنید. [منابع و manifest](../docs/sources/README.md).

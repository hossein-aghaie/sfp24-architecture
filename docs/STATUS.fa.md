## چه چیزی در مبنای ۲ نوامبر ثبت شده است؟

| قابلیت | موجود | محدودیت |
|---|---|---|
| حساب/شرکت/دسترسی | هویت شرکت، نقش پایه، مجوز و scope سمت سرور | SDK عمومی Identity برای همهٔ ماژول‌های آینده تثبیت نشده |
| تعاریف پایه | افراد، تجهیزات/منابع، قطعه، OP، شیفت و واحدها | خط/سالن/منبع مفهوم یکسان ندارند؛ توسعهٔ همهٔ روابط آینده کامل نیست |
| هاب داده | منبع، تگ، ساختار پیام، دریافت HTTP، تست و حالت دریافت | اجرای HTTP جاری با پذیرش کامل قرارداد صنعتی rc.4 یکی نیست |
| پارامتر | تعریف داده و منابع با نوع/واحد/نسخه؛ اتصال محدود تولید | مصرف عمومی همهٔ پارامترها توسط تمام ماژول‌ها ساخته نشده |
| ثبت و گزارش تولید | گزارش دستی، بازهٔ کار و مصرف محدود شمارش معتبر | موتور عمومی پلان، OEE و گردش تأیید چندمرحله‌ای نیست |
| یادداشت دستگاه | یادداشت و مخاطب مجاز با هویت موجود | دستورکار تعمیرات و موتور کارتابل جامع نیست |
| تعریف میز | ذخیرهٔ نسخه‌دار، کپی، اختصاص چند میز و میز شروع | محتوای داخل میز AssignedDesk هنوز نمونهٔ تعاملی است |
| سه‌بعدی | صحنه، انتخاب تجهیز و حالت‌های نمایش | تمام لایه‌های تخصصی، داده/ماژول عملیاتی ندارند |
| Training | پیش‌نمایش تألیف با JSON محلی و مجوز اختصاصی در شاخهٔ مستقل | LMS، آزمون عملیاتی، Gap، Onboarding و AI متصل ساخته نشده‌اند |
| OEE، CMMS، Planning، MRP | نامزد طراحی | ماژول عملیاتی عمومی تلقی نشوند |
| AI و دانش مشترک | جهت محصول و پیشنهاد فنی | Provider، Retrieval و import بستهٔ واقعی اجرا نشده |

## آزمون و استقرار

در گزارش تحویل b3f203b، ۱۷۰ تست عمومی موفق و یک skip، ۶۶ تست یکپارچهٔ MariaDB موفق، build/typecheck و بررسی‌های مرورگر با fixture ثبت شده‌اند. این اعداد **اجرای قبلی** هستند؛ در مرتب‌سازی اسناد دوباره Runtime تست نمی‌شود. مشاهدهٔ UI آزمایشی، تست دستگاه واقعی یا آماده‌بودن یک ماژول کامل نیست.

در پایلوت محلی، کنترل۹ و tenant۱۸ قبلاً گزارش‌شده‌اند. هیچ محیط جدیدی با این سند ارتقا پیدا نمی‌کند؛ راه‌اندازی/backup/migration باید به همان نسخه و محیط وابسته بماند. [راهنمای اجرا](operations/README.md).

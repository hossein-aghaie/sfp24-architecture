# وضعیت اتصال داده

مسیر جاری: تعریف و تست فنی منبع و تگ در هاب، انتشار انتخابی برای شرکت و تخصیص تگ به ورودی ماشین در WEB. راهنمای قدم‌به‌قدم نهایی پس از پیاده‌سازی و تأیید رابط تهیه می‌شود؛ قرارداد مصوب به معنی آماده‌بودن اجرای آن نیست.

مرجع: [معماری](../ARCHITECTURE.md)، [وضعیت واقعی](../CURRENT-STATE.md) و [قرارداد مشترک](../../packages/telemetry-contract/README.md).

فرستندهٔ آزمایشی مستقیم قدیمی WEB بازنشسته شده است. برای شبیه‌ساز آزمایشگاهی هاب، [راهنمای اجرا](../RUNBOOK.md) را بخوانید. این ابزار دریافت صنعتی واقعی را اثبات نمی‌کند.

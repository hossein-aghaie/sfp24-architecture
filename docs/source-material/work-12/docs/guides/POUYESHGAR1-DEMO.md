## شواهد

ورود هر ۱۰ اپراتور و شیفت اختصاصی آن‌ها روی MariaDB واقعی بررسی شد. مرورگر واقعی، فرم mojtaba و ali با انتخاب درست شیفت، منع API مدیریت کاربران و نمای سه‌بعدی مدیر را بررسی کرد. موقعیت/چرخش/ابعاد/نوع/مدل هر ۱۶ تجهیز با `initialLayout()` فاز دوم مقایسه شد. شواهد تصویری و نتیجه در مسیر ignored `.local/qa/pouyeshgar1` است. Typecheck برنامه و ابزارها، Build و ۶۷ تست عادی پاس شدند؛ یک مجموعهٔ کامل MariaDB در اجرای عادی Skip است و جایگزین آزمون میدانی نیست.

Migration نسخهٔ ۹ ستون اختیاری `people.default_shift_id` را اضافه می‌کند؛ ارجاع و محل شیفت در سرویس اطلاعات پایه اعتبارسنجی می‌شود. این ترجیح در `context.me.defaultShiftId` بازمی‌گردد و در فرم پیشنهاد می‌شود. اعمال مجدد Migration ایمن است؛ چک‌سام نسخه‌های قبل تغییر نکرده است.

ابزار `tools/local-demo/seed-pouyeshgar1.ts --create-pouyeshgar1` فقط در دیتابیس آزمایشی مستقل تأییدشده اجرا می‌شود و اگر شرکت وجود داشته باشد، از بازنویسی یا Reset آن خودداری می‌کند. فایل‌های وضعیت و مشخصات ورود زیر `.local/pouyeshgar1/private` خارج Git هستند. برای کار روزمره، سرویس‌ها را با راه‌انداز فعلی روشن کنید؛ Seed را دوباره اجرا نکنید.

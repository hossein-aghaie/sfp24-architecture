۵۸schema و۱۵۰حساب محدود مربوط به تست‌های تاریخی از MariaDB آزمایشی۳۳۱۷ حذف شدند. control و tenant جاری حفظ و تعداد رکوردهای۸۰جدول قبل/بعد برابر بود. یک dump خصوصی حدود۱٫۹MB و مجوزهای حساب‌های بازنشسته در .local/archive/cleanup-2026-10-28/private حفظ شده‌اند؛ restore این snapshot هنوز آزموده نشده است. دادهٔ شرکت فعال reset نشد؛ حذف دادهٔ تستِ مجاز را با حذف همهٔ اطلاعات جاری یکی نگیریم.

آزمون اختیاری MariaDB اصلاح شده تا در اجرای عادی schema/حساب/فایل موقت خودش را جمع کند؛ فقط export fixture صریح برای بررسی دستی حفظ می‌شود. اسکریپت Create-Fixture از پیکربندی تأییدشدهٔ جاری می‌خواند، نه control بازنشسته. فایل‌های fixture/پیکربندی قدیمی خصوصی به آرشیو منتقل شدند و مرجع اجرا نیستند. یک کپی تولیدشدهٔ simulator برای QA پاک شد؛ store وابستگی مشترک با دمو، MariaDB runtime و دادهٔ فعال cache تلقی نشدند.

در مشاهدهٔ واقعی ویندوز، passive TCP پورت۳۳۱۷ گاهی CLOSED گزارش شد درحالی‌که همان پردازش MariaDB اتصال را می‌پذیرفت. fallback اصلاح شد: پس از اتصال موفق، PID اتصال server-side یا PID تخصیص‌یافتهٔ ثابت قبل/بعد باید قابل‌اثبات باشد؛ موفقیت connect به‌تنهایی، مالک ناشناس یا تغییر PID پذیرفته نمی‌شود. بررسی مسیر/زمان ساخت/رکورد پردازش در Manage همچنان برقرار است و Stop دیتابیس مشترک را متوقف نمی‌کند. inventory مستقل Get-NetTCPConnection نیز برای ردیف‌های حذف‌شدهٔ netstat اضافه شد؛ تعارض PID دو منبع رد می‌شود. آزمون PowerShell شامل۸ مورد مالکیت،۱۱ مورد inventory،۵ مورد fallback و۲ مورد inventory مستقل موفق شد. مالک اکنون Stop/Start محلی را مجاز کرده است؛ این اجازه شامل استقرار روی Raspberry Pi یا محیط دیگر نیست.

### اصلاح UX میزساز — ۲۰۲۶-۱۱-۰۱
عنوان تکراری داخلی حذف و برگشت به فهرست در پایین پنل ویرایش قرار گرفت؛ پنل تنظیمات با اسکرول داخلی، ذخیره/برگشت را هنگام بررسی پیش‌نمایش بلند در دسترس نگه می‌دارد. روش ثبت تعداد از مشخصات عمومی میز به محتوا منتقل شد و فقط برای بخش نتیجهٔ تولید ظاهر می‌شود. تعریف ذخیره‌شده/قرارداد API و مجوزها در این اصلاح تغییری نکردند؛ محتوای میز همچنان نمایشی است.

# Pouyeshgar Data Hub — local lab

هاب مستقل مدیریت شرکت، دستگاه و جریان داده؛ رابط انگلیسی با تغییر به فارسی و RTL. شامل ۵ شرکت نمونه، ۱۰ دستگاه نمونه برای هر شرکت، مدیریت دسترسی و شبیه‌ساز مستقل EdgeBox است.

**راهنمای کامل نصب از مخزن، روشن‌کردن، خاموشی و رفع خطا:** [RUNBOOK.fa.md](docs/RUNBOOK.fa.md).

داخل پنل، منوی **Help & guide / راهنما** نمودار قابل انتخاب مسیر ورود داده، برچسب‌گذاری، ثبت و تحویل را نشان می‌دهد. در همان راهنما، مرجع تعریف شرکت، مثال شمارش/صفر/مقدار ناموجود و تفاوت دریافت، ذخیره و تحویل توضیح داده شده است. [تصمیم مرجع شرکت‌ها](docs/ADR-001-COMPANY-OWNERSHIP.md) برای اتصال آینده ثبت شده؛ همگام‌سازی با برنامهٔ اصلی هنوز فعال نیست.

منوها و بخش‌ها و کادرهای راهنما در تاریخچهٔ مرورگر ثبت می‌شوند؛ Back و Forward مسیر قبلی را برمی‌گردانند و رفرش صفحه همان آدرس را باز می‌کند. نمونهٔ لینک مستقیم: `http://127.0.0.1:5220/#/help/tags`. پس از دریافت این به‌روزرسانی یک‌بار صفحه را رفرش کنید؛ مسیرهای طی‌شده در نسخهٔ قدیمی قابل بازیابی نیستند.

**برای هماهنگی با سشن برنامهٔ اصلی:** [سند تحویل و پیشنهاد قرارداد اتصال](docs/INTEGRATION-HANDOFF.fa.md)؛ شامل وضعیت واقعی کد، نقش Dev Admin و Company Admin، رسیدن نام و شناسهٔ شرکت به هاب، نگاشت سیگنال به ماشین، رویدادهای شمارش/هشدار/دوربین، به‌روزرسانی خودکار و متن آمادهٔ ارسال است. این سند به‌تنهایی اتصال واقعی یا پشتیبانی v2 را پیاده‌سازی نمی‌کند.

پس از نصب وابستگی‌ها، از داخل پوشهٔ پروژه: `Start.cmd` برای روشن‌کردن، `Stop.cmd` برای خاموش‌کردن و `Start.cmd -Build` برای ساخت مجدد و اجرا. توقف، اطلاعات را حذف نمی‌کند.

## اجرا در همین ویندوز

نیاز: Node.js 24+ و وابستگی‌های همین پوشه. Docker و WSL لازم نیستند. برای اجرای نسخهٔ ساخته‌شده:

```powershell
pwsh -NoProfile -File 'D:\git\pouyeshgar-industrial-platform\scripts\Start-Lab.ps1'
```

برای ساخت دوباره پس از تغییر کد، `-Build` اضافه کنید. اسکریپت پیش از اجرا پورت‌ها را بررسی می‌کند و هیچ برنامهٔ دیگری را متوقف نمی‌کند.

- پنل: http://127.0.0.1:5220
- شبیه‌ساز مستقل: http://127.0.0.1:5223؛ با دکمهٔ **Start all agents** شروع می‌شود.
- اطلاعات ورود: فایل محلی `private/access.json`. آن را فقط خودتان بخوانید؛ در پیام، Git یا تصویر منتشر نکنید.
- توقف فقط فرایندهای ثبت‌شدهٔ همین پروژه:

```powershell
pwsh -NoProfile -File 'D:\git\pouyeshgar-industrial-platform\scripts\Stop-Lab.ps1'
```

توقف داده‌ها را حذف نمی‌کند. برنامهٔ اصلی، Ubuntu، Docker و دیتابیس MariaDB اصلی دست‌نخورده‌اند.

## شروع ساده

۱. وارد پنل شوید؛ از بالای صفحه شرکت را انتخاب کنید.
۲. در شبیه‌ساز **Start all agents** را بزنید. در **Received data** داده‌های شمارش و دما را ببینید. شمارش صفر معتبر است.
۳. در **Devices** جزئیات، سیگنال‌ها و راهنمای اتصال هر دستگاه را ببینید. **Commands** فقط عامل جمع‌آوری را کنترل می‌کند.
۴. شرکت بدون EdgeBox می‌تواند از **Data sources → File import** برای Excel/CSV یا **API polling / Database** استفاده کند. ورود فایل، پیش‌نمایش و نگاشت ستون دارد.
۵. **Delivery** مقصد و وضعیت تحویل را نشان می‌دهد. مقصد محلی `/api/lab/receiver` برای آزمایش است؛ برنامهٔ اصلی متصل نیست.

دیتابیس داخلی این آزمایش SQLite مستقل است. این تصمیم مهاجرت دیتابیس اصلی نیست. اتصال واقعی MariaDB هنوز آزمایش نشده؛ فقط دیتابیس مستقل آزمایشی مجاز است. تمام شنونده‌ها روی localhost هستند؛ این نسخه برای انتشار عمومی آماده اعلام نشده است.

## توسعه و آزمون

نسخه‌ها در `package.json` و `pnpm-lock.yaml` ثابت شده‌اند. نصب محلی بدون تغییر PATH یا نصب سراسری:

```powershell
pnpm install --frozen-lockfile --store-dir private/pnpm-store --config.cache-dir=private/pnpm-cache --config.state-dir=private/pnpm-state
pnpm test
pnpm build
```

مجوز اجرای postinstall فقط برای esbuild در `pnpm-workspace.yaml` ثبت شده است. آزمون‌های اصلی SQLite موقت، HTTP محلی و MQTT محلی خودشان را می‌سازند. تست مرورگر `tests/browser.mjs` از Playwright موجود محیط و Edge نصب‌شده استفاده می‌کند؛ مسیر ابزارها روی رایانهٔ دیگر باید تنظیم شود و تعدادی رکورد آزمایشی در همین پنل می‌سازد.

معماری و نقاط توسعه: [ARCHITECTURE.md](docs/ARCHITECTURE.md). قراردادها: [API.md](docs/API.md). نتیجهٔ آزمون و مصرف منابع: [VALIDATION.md](docs/VALIDATION.md). هیچ کد یا برند محصول دیگری کپی نشده؛ فهرست مجوزهای وابستگی‌ها جدا ثبت می‌شود. حق استفادهٔ تجاری نهایی باید با مجوزهای نسخه‌های قفل‌شده و سیاست حقوقی شما تطبیق داده شود.

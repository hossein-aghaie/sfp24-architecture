# سوابق تاریخی

این پوشه مدرک تصمیم‌ها، تحویل‌ها و آزمون‌های گذشته است؛ دستور توسعه یا راه‌اندازی جاری نیست. مرجع فعلی [START-HERE](../START-HERE.md) و [CURRENT-STATE](../CURRENT-STATE.md) است.

- deliveries/: تحویل، پیشرفت و QA تاریخ‌دار
- research/: پژوهش و راهنماهای اولیه
- state-2026-10-19/: نسخهٔ پیشین اسناد جاری پیش از جمع‌بندی
- telemetry-v1/: هاب قبلی در WEB و فرض‌های پیش از قرارداد جدید
- data-hub/: سوابق مخزن مستقل، مجوزها، پیشنهادها و ممیزی‌های آن

نسخه‌های قدیمی سورس با tagهای archive/2026-10-19 در GitHub محفوظ‌اند. اسناد معتبر محصول و قرارداد اجرایی از این پوشه کپی یا بازتعریف نشوند. فایل‌های خصوصی محیط قبلی در .local/archive هستند و عمداً وارد Git نشده‌اند.

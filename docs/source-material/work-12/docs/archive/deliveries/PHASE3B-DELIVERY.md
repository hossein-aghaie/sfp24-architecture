## آنچه قابل استفاده و آزمایش شده است

- اطلاعات پایهٔ مشترک: کارخانه/کارگاه، سالن فیزیکی، تجهیز/خط/ایستگاه، قطعه و واحد، OP، افراد با اتصال اختیاری به حساب ورود، شیفت شب، وقفه، تقویم و علت ضایعات. ویرایش نسخه‌دار و غیرفعال‌سازی بدون حذف سوابق.
- دسترسی مستقل هر کاربر، جدا از عنوان شغلی و الگوی اولیه، با محدودهٔ شرکت/کارخانه/سالن/منبع و کنترل سمت سرور. چند مدیر کامل در سقف ظرفیت مجازند؛ آخرین مدیر مؤثر فعال محافظت می‌شود. تغییر دسترسی نیازمند تأیید رمز مدیر است و نشست‌های کاربر را باطل می‌کند.
- ثبت دستی چندردیفی موبایل: انتخاب منبع، قطعه/نام موقت، OP و شیفت، بازهٔ قابل ویرایش، سالم و ضایعات نهایی، چند علت با شمارش سازگار، پیش‌نویس/ادامه و ثبت نهایی. ۱۲۰ سالم + ۳ ضایعات = ۱۲۳ پردازش‌شده؛ خالی و صفر متفاوت‌اند.
- اصلاح گزارش نهایی با مجوز، علت و تاریخچهٔ قبل/بعد؛ درخواست اصلاح برای خوانندهٔ عادی. داده‌ها در MariaDB همان شرکت می‌مانند و پس از restart API بازیابی می‌شوند.
- گزارش و داشبورد واقعی با فیلتر تاریخ/محل/منبع/قطعه/OP/شیفت و فیلتر افراد با مجوز جدا. جمع فقط در ترکیب یکسان منبع، قطعه، OP و واحد؛ بدون OEE یا محصول نهایی ساختگی. نمودار روزانه Hover دقیق، Legend و Zoom/Reset واقعی دارد.
- CSV قطعات: قالب دانلودی UTF-8، نگاشت ستون، پیش‌نمایش و خطای ردیفی، تأیید اتمی، انقضا و جلوگیری از تکرار، خروجی واقعی و ایمن برای فرمول‌های صفحه‌گسترده. هیچ قطعهٔ موجودی با Import بازنویسی یا حذف نمی‌شود.

## تست دستی صاحب محصول

برنامه آماده است: `http://127.0.0.1:5176/company/pouyeshgar-test/login` با **همان رمز فعلی** مدیر شرکت. ورود صاحب نرم‌افزار همچنان `/owner/login` است.

۱. اطلاعات پایه ← کارخانه/کارگاه، سپس دستگاه، قطعه و OP را بسازید.
۲. کاربران و دسترسی‌ها ← کاربر جدید، برگهٔ ورود خصوصی و پیشنهاد دسترسی اپراتور؛ در صورت نیاز فرد را به حساب ورود وصل کنید.
۳. با حساب اپراتور وارد شوید؛ سالم ۱۲۰ و ضایعات ۳ با علت/توضیح ثبت، پیش‌نویس و سپس نهایی کنید.
۴. با حساب مدیر در سوابق/گزارش تولید همان اطلاعات را ببینید؛ اصلاح نهایی فقط با علت ثبت می‌شود.
۵. اطلاعات پایه ← قطعات ← ورود CSV؛ ابتدا قالب و پیش‌نمایش، سپس تأیید.

از کنترل و پنج دیتابیس شرکتِ محیط آزمایشی، پیش از Migration افزایشی پشتیبان خصوصی گرفته شد. نسخهٔ نهایی Schema: کنترل **۴**، شرکت **۴**. API 5186، وب 5176، worker و MariaDB 3317 روی loopback آماده‌اند. رمزها و ظرفیت حساب‌ها تغییر نکردند؛ اطلاعات فاز دوم منتقل یا حذف نشد. هیچ Windows Service، ERP، سخت‌افزار، Branch دیگر یا Stash تغییر نکرد؛ Deploy/PR/Merge/Tag انجام نشد.

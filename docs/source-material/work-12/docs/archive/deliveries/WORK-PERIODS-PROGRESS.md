- Form no longer invents 08:00–16:00 when no shift exists. Current configured shift/last authorized report selections suggest defaults; Start/Finish is optional, manual retrospective periods remain supported. Finished work can be reported later while the next begins. Draft context survives a later login.
- `/company/production/device-count`: independent, scoped Reports permission; separate device-source panel in production summary. Raw processed counts are never added to operator report totals and are not good output/OEE/runtime. Missing/conflicted periods remain partial.
- Resource-scoped change notifications after successful ingestion commit and binding/connection changes. Authenticated long polling waits for a source event; no fixed 15-second count fetch. Short reconnect backoff and focus resync remain. This is single API process notification infrastructure; cross-process/broker pub-sub is not built.

Separate privileged worker validates company-to-database mapping, actual isolated data directory, runtime DB grants and tenant metadata before dropping that tenant database/runtime user and removing company/user/secret records.

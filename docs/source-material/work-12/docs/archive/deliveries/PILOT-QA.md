# شواهد QA پایلوت — 2026-10-13

> شواهد این سند متعلق به نسخهٔ پایهٔ ۰٫۵ است. [گزارش Phase 2](PHASE2-DELIVERY.md) و `.local/qa/phase2/after/result.json` نتیجهٔ نسخهٔ فعلی را ثبت می‌کنند.

محیط: Windows، Node 24.19، pnpm 11.25، Vue/TypeScript/Vite، Chrome موجود و Playwright headless با WebGL/SwiftShader. تست روی loopback و دادهٔ ناشناس نمونه انجام شده، نه کارگاه/PLC واقعی. خروجی‌های محلی در `.local/qa` نگهداری می‌شوند؛ تصاویر مرجع و رمزها در Git نیستند.

## بررسی کد و اجرای واقعی

- `pnpm install --frozen-lockfile --store-dir "$PWD\.local\pnpm-store"`: موفق. بررسی اختیاری نسخهٔ جدید pnpm در sandbox خطای شبکه داشت؛ نصب frozen و وابستگی‌های پروژه موفق بود.
- `pnpm test`: **۱۶ از ۱۶ موفق**؛ حفظ چیدمان/هویت، هندسهٔ چرخش، بازه‌های تقویمی، هم‌سازی دادهٔ نمونه، فرمول/مخرج KPI، عدم ساخت OEE سالن، شیفت شب/تعطیلات، قرارداد ingest، auth/RBAC/scope، تکرار/هم‌پوشانی، بازهٔ ناقص، نسخهٔ تعریف KPI، ادامهٔ شبیه‌ساز و دوام فایل.
- `pnpm build`: موفق؛ شامل `vue-tsc --noEmit` برای client، server و tests و build تولید Vite.
- Fastify روی `127.0.0.1:5184` و Vite روی `127.0.0.1:5174` اجرا شدند. شبیه‌ساز دادهٔ زمان‌دار را ثبت کرد؛ اجرای مجدد همان دقیقه صفر رکورد جدید ثبت کرد و تعارض نداشت.
- `node scripts/browser-qa.mjs`: موفق؛ افزودن/انتخاب/چرخش، ذخیره/بازخوانی، JSON import/export، چندسالن/نمای بالا، تفکیک پایش/تنظیمات، کارت/جدول، نمایشگر و عرض موبایل نسخهٔ پایه.
- `node scripts/refined-qa.mjs`: موفق؛ دوبعدی مستقل، لایهٔ مشترک، جزئیات دستگاه/گروه نمونه، حفظ بازه، رویداد/تعمیرات، پوسته‌ها و خاموش‌کردن دادهٔ نمونهٔ نسخهٔ next.
- `node scripts/pilot-qa.mjs`: موفق؛ نمونهٔ مشترک Three.js بین Immersive/Explore، حفظ انتخاب و بازه، Analytics و جزئیات، فارسی RTL/انگلیسی LTR، نبود overflow افقی، demo off، فیلتر API بیننده به یک تجهیز، ممنوعیت فرم تنظیمات برای بیننده، ثبت/حذف شیفت، ترجیحات پایدار، ویرایشگر انگلیسی و بازگشت به پایش، انتخاب مستقیم مدل با raycast و برچسب‌های پنهان، و تغییر تصویر واقعی canvas پس از wheel.

اسکریپت QA پیش از شروع نتیجه را running می‌نویسد و فقط بعد از گذشتن همهٔ assertionها `passed:true` ثبت می‌کند؛ نتیجهٔ قدیمی هنگام شکست، موفقیت جدید محسوب نمی‌شود. خروجی `.local/qa/pilot/result.json` شامل checks و errors است. تست‌های قدیمی در مسیر `/?baseline=1` همان امکانات حفظ‌شده را بررسی می‌کنند.

## تصاویر واقعی و اصلاح بصری

برای **هر سه نمای Immersive/Explore/Analytics و Device Detail** تصویر واقعی در 1366×768، 1920×1080 و 800×1000 گرفته شد. برای سه نمای موبایل 390×844 و نسخهٔ انگلیسی دسکتاپ، تنظیمات API و ویرایشگر نیز تصویر ثبت شد. نام‌ها به‌صورت `1366-immersive-fa.png` و مشابه در `.local/qa/pilot` هستند.

مرجع‌های 01/05 برای چیدمان واقعی، 02 برای پوستهٔ آبی، 03 برای تفاوت سه نما و 04 برای فضای جزئیات بررسی شدند. مقایسهٔ بازبینی اول نشان داد دوربین صحنه را کوچک نشان می‌داد، برچسب دریل‌ها متراکم بود و نوار رویدادها در دسکتاپ پایین می‌افتاد. قاب دوربین اختصاصی پایلوت، حذف برخورد برچسب‌ها، ارتفاع stage، پنل قابل اسکرول و کنترل نمای بالا/بازنشانی جدا اصلاح شدند؛ خروجی بعد از اصلاح دوباره از مرورگر گرفته شد.

مرجع کارخانهٔ عظیم مفهومی بازسازی نشده؛ همان ۱۶ تجهیز، پله، انبار میانی و سالن‌های واقعی مدل پایه حفظ شده‌اند. تعداد تجهیزات یا جای آنها از تصویر مفهومی اخذ نشده. کارت OEE فقط برای تجهیز منتخب است، عدد OEE سالن یا هدف ساختگی نمایش داده نمی‌شود. لوگوی رسمی پویشگر موجود/تأییدشده نیست؛ نام متنی و نماد عمومی کارخانه استفاده شده است. تطبیق پیکسلی با مفهوم ادعا نمی‌شود.

## محدودیت اعتبارسنجی

- **MariaDB واقعی اجرا نشده است.** آداپتور و migration typecheck شده‌اند، ولی SQL، قفل/rollback و seed روی سرور واقعی integration-test نشده‌اند. تست دوام فعلی مربوط به آداپتور فایل محلی است.
- نمونهٔ شبیه‌ساز، صحت firmware واقعی یا دادهٔ PLC/ERP را ثابت نمی‌کند. سرور ورود `source=edge` را صریحاً رد می‌کند تا قرارداد firmware مشخص شود.
- صحت الگوریتم شیفت/تعطیلات تست شده؛ چند تقویم هم‌پوشان، استثنای جایگزینی ساعت و انتساب کارکنان/تیم به شیفت کامل نیست.
- فرمول‌های چهارگانه و نسخهٔ تعریف تست شده‌اند؛ تاریخچهٔ کامل تعریف و فرمول آزاد تجاری موجود نیست.
- تست headless جای ممیزی WCAG، آزمون بار/قطعی برق، مانیتور صنعتی واقعی، مرورگر Safari یا شبکهٔ کارخانه را نمی‌گیرد.
- کاربران/نقش‌های قابل مدیریت در UI، CMMS، planning، finance، products/operations/lines، lifecycle هشدار و انتقال تاریخچهٔ مکان هنوز کامل نیستند. [جدول قابلیت‌ها و راهنمای اجرا](../research/PILOT-RUNBOOK.md) مرزهای محصول را مشخص می‌کند.

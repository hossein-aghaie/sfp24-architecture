# REQ-core-0001 — درخواست داخلی به مدیر سامانهٔ شرکت

تاریخ: ۲۰۲۶-۱۱-۱۴
مبدأ: مالک محصول، سناریوی راه‌اندازی شرکت
مقصد: هستهٔ مشترک، هویت و فضای کاری
وضعیت: ثبت‌شده / Proposed

مسئول فنی یا برنامه‌ریز باید بتواند افزودن قطعه و عملیات ساخت، تعریف شیفت یا اصلاح اطلاعات پایه را از مدیر سامانهٔ همان شرکت درخواست کند. مثال: مسئول فنی نام، کد و واحد قطعه و عملیات پیشنهادی را می‌دهد و مدیر سامانه پس از بررسی، تغییر را در تعاریف شرکت ثبت می‌کند.

بررسی پیشنهادی شامل ثبت درخواست، وضعیت قابل پیگیری، نیاز به تکمیل اطلاعات، پاسخ مدیر و ارتباط با رکورد نهایی است. درخواست و پاسخ در محدودهٔ همان شرکت و افراد مجاز دیده شوند. ثبت درخواست به‌خودی‌خود مجوز تغییر داده یا اعمال خودکار تغییر ایجاد نکند.

گزینهٔ فعلی، استفاده از نامه یا ابزار تیکت موجود شرکت است. پیش از طراحی، امکان استفاده از کارتابل و اعلان فعلی، موارد خارج از پوشش آن‌ها و نیاز واقعی به تاریخچه یا ضمیمه بررسی شود. مرجع مسئولیت و دسترسی [هویت و دسترسی](../IDENTITY-AND-ACCESS.fa.md) است.

تصمیم دربارهٔ گردش، اختیارها و زمان اجرا باز است. هنوز پیاده‌سازی یا آزمون انجام نشده است.

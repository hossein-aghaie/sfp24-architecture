# هویت، دسترسی و ظرفیت

**مرجع موضوعی جاری؛ وضعیت موجود بر مبنای b3f203b و نیازهای حل‌نشده جدا شده‌اند.** قرارداد عمومی تازهٔ Identity یا تغییر سیاست تجاری با این صفحه تصویب نمی‌شود.

## تعریف‌ها و مالکیت

| مفهوم | معنی و مرز |
|---|---|
| شرکت / Tenant | مرز مستقل داده، تنظیمات، خرید قابلیت و ظرفیت؛ دو شرکت مستقل با مالک یکسان، خودکار یک tenant نمی‌شوند |
| Person | پروندهٔ انسان در people همان شرکت؛ می‌تواند بدون Login فعال سابقه داشته باشد |
| Account | هویت ورود و نشست؛ ارتباط اختیاری Person با login_user_id صریح است |
| عنوان شغلی / Position | توصیف مسئولیت یا الگوی آمادهٔ دسترسی؛ عنوان متنی، مجوز یا صلاحیت اثبات‌شده نیست |
| Role / permission rules | نقش پایه و قواعد مجوز موجود؛ با مأموریت امروز یا میز انتخاب‌شده یکی نیست |
| Scope | محدودهٔ معتبر اقدام/خواندن، مانند شرکت، سایت یا تجهیز؛ کنترل نهایی سرور است |
| Entitlement | قابلیت خریداری/فعال‌شدهٔ شرکت؛ دادن permission، خرید ماژول ایجاد نمی‌کند |
| Qualification | نتیجهٔ تخصصی شایستگی با شواهد؛ [تعریف دامنهٔ آموزش](../modules/training/SKILL-GAP-LMS.fa.md) |
| Desk assignment | انتخاب ابزار و مقصد ورود؛ [مرجع فضای کاری](WORKSPACES.fa.md)، نه منبع اجازهٔ تازه |

## رفتار موجود

actor از نشست سرور می‌آید. هویت دیتابیس/شرکت ارسالی مرورگر جایگزین context معتبر نیست. مجوز مؤثر به فعال‌بودن شرکت، entitlement/readiness قابلیت، اجازهٔ اقدام و محدوده بستگی دارد. دکمهٔ مخفی امنیت نیست. Provider دسترسی عادی به دادهٔ عملیاتی مشتری ندارد؛ مسیر پشتیبانی مستقل، محدود و auditشده است.

سیاست ظرفیت موجود active-humans-v1 حساب‌های فعال را می‌شمارد؛ Person بدون حساب فعال همان مصرف Login نیست. عوض‌کردن اسم Role به learner، حساب را خودکار از seat_limit معاف نمی‌کند. حسابِ چندمسئولیتی برای تولید و آموزش نباید به ایجاد Person تکراری منجر شود.

مجوز ثبت برای خود/دیگری، خواندن خود/دیگران و اصلاح گزارش با عنوان مدیر/اپراتور یکی نیست. سیاست‌ها در API کنترل می‌شوند؛ انتخاب Workspace یا کارت، مجوز عملیاتی صادر نمی‌کند.

## چندسایتی و چندشرکتی

قاعدهٔ تجاری ثبت‌شده، شرکت مستقل = tenant مستقل است. امکان رشد یک شرکت به چند سایت، نیاز معماری است؛ مدل اجرایی پایلوت فعلی و پوشش کامل چندکارخانه یکی نیستند. این صفحه نه محدودیت «برای همیشه یک کارخانه» ایجاد می‌کند، نه چندکارخانهٔ کامل را اجراشده معرفی می‌کند.

## اختلاف‌های باز با آموزش

| موضوع | وضعیت |
|---|---|
| حساب شخصی امن فراگیر با همان Person | نیاز ثبت‌شدهٔ محصول Training؛ روش اجرایی هنوز کامل نیست |
| قیمت و سهمیهٔ فراگیر | Open؛ تصمیم تجاری مالک لازم است |
| دعوت، credential، حساب چندمسئولیتی و سقف ظرفیت | باید با سرویس موجود طراحی و آزموده شوند |
| مسئولیت و انتساب تاریخ‌دار | قرارداد مشترک نهایی هنوز باز است |

[ممیزی تفصیلی Seat](IDENTITY-AND-ENTITLEMENTS-AUDIT.fa.md) برای گزینه‌ها و شواهد است. هیچ محدودیت فعلی با متن این سند دور زده نمی‌شود.

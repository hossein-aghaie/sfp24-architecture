# UI Contributions — Draft

> **Status:** Proposed · **Owner:** Core UX · **Updated:** 2026-11-02

ماژول Training ممکن است به یک Person بخش «شایستگی»، به فراگیر «آزمون‌های من»، به ارزیاب «کارتابل ارزیابی» و به مدیر «نمودار پوشش مهارت» ارائه کند؛ **بدون ایجاد Profile یا Engine موازی**.

| Contribution | نمونه |
|---|---|
| Profile/Resource section | آموزش شخص یا تعمیر تجهیز |
| Form & Action | ثبت تولید، ارزیابی |
| Inbox/Assignment | کارهای واگذارشده |
| Metric/Widget | OEE، روند تگ |
| Page/Workspace | گزارش تخصصی |

نمایش وابسته به entitlement، readiness، permission، scope، company policy و preferences است؛ کنترل API جدا و الزامی است.

پرسش باز: مرز فرم‌ساز عمومی/کامپوننت تخصصی، رجیستری پویا، داشبورد مستقل شبیه Grafana، میزهای چندمسئولیتی و ارتباط با 3D.

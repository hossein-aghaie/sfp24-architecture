## محدودیت شواهد

بخش‌هایی از این بحث‌ها در گفتگوهای ChatGPT بوده‌اند که **متن کامل و لفظ‌به‌لفظشان اکنون در فایل منبع حاضر نیست**. هرجا توضیح بر پایه فهم فعلیِ گفتگو و تطبیق اسناد است، «بازسازی تحلیلی» به کار رفته و نقل‌قول ساختگی نوشته نشده است. اگر کاربر بعداً متن دقیق یک یا دو پیام را ارائه کرد، آن را به‌صورت transcript جدا با منشأ و برچسب مشخص ثبت کنید، نه جایگزین متن تاریخی یا ادغام بدون هشدار.

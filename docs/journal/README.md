# گفتگوها و اتاق فکر

اینجا سابقهٔ فکر دربارهٔ **کل محصول و موضوعات مشترک** است: چرا برنامه شکل گرفت، چه گزینه‌هایی بررسی شدند، چه مسیری شکست خورد یا تغییر کرد و کدام سؤال هنوز باز است. هر موضوع تازه الزاماً به معنی تصمیم یا دستور اجرا نیست.

| دامنهٔ گفتگو | مسیر |
|---|---|
| هدف محصول، شیوهٔ کلی توسعه یا بحث مشترک چند بخش | همین پوشه و فهرست تاریخ‌ها و موضوع‌های زیر |
| موضوع اختصاصی هسته یا هاب داده | [سوابق و اتاق فکر هسته](../core/RECORDS.md)؛ از آنجا به فکر، تحقیق، آزمایش و درخواست مربوط بروید |
| موضوع اختصاصی یک ماژول | [فهرست ماژول‌ها](../modules/README.md)، سپس راهنما و فهرست سوابق همان ماژول |

اصل یک گفتگوی چندموضوعی فقط یک بار نگه داشته می‌شود و بخش‌های مرتبط از جاهای دیگر لینک می‌گیرند. متن خام، گزیده و خلاصه باید برچسب جدا داشته باشند. [قواعد ثبت و حفظ سابقه](../governance/DOCUMENTATION-POLICY.md).

# سیاست مستندسازی

> **Status:** Approved documentation workflow · **Updated:** 2026-11-02

**Single Source of Truth:** هر مفهوم یک سند مالک دارد. سایر اسناد لینک می‌دهند؛ قرارداد، Permission، مدل Person یا فرمول KPI را کپی نمی‌کنند.

**لایه‌ها:** Journal (تاریخچه) → Research/Proposals (شواهد و گزینه‌ها) → ADR (تصمیم مصوب/ردشده) → Contracts (قرارداد نسخه‌دار) → Implementation (تسک آزمون‌پذیر). بین این وضعیت‌ها جهش خودکار وجود ندارد.

**تقسیم فایل:** هر پوشه README کوتاه؛ هر فایل یک مسئولیت یا تصمیم؛ گفتگوها تاریخ‌دار و موضوعی، نه یک متن بی‌انتها. معیار تقسیم، استقلال موضوع و مخاطب است نه صرفاً تعداد خط.

**خوانایی GitHub:** Markdown، فهرست مطالب، جدول، Mermaid و لینک نسبی؛ شکل‌های قابل‌ویرایش ترجیح دارند. متن اصلی گفتگو از خلاصه ایجنت متمایز باشد.

**منبع:** ادعا شامل مرجع نسخه/commit، تاریخ و روش بررسی. استاندارد شامل شماره نسخه، دامنه و منبع اولیه. اسناد اجرا را اثبات نمی‌کنند.

**انتقال:** هنگام move/rename، همه لینک‌ها و README مالک را اصلاح کنید. تاریخچه رد و جایگزینی حذف نشود؛ ADR جدید به ADR سابق پیوند بخورد.

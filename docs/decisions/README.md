## تصمیم تخصصی یا تصمیم مشترک؟

این فهرست برای تصمیم‌های کل محصول و قواعد مشترک است. تصمیم فقط مربوط به یک ماژول در پوشهٔ همان ماژول ثبت می‌شود و از README آن قابل دسترسی است. فهرست موجود آموزش حفظ می‌شود؛ تصمیم‌های جدید از آن لینک می‌شوند، نه اینکه در دو جا مستقل نوشته شوند.

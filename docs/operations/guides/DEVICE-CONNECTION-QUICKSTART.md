# وضعیت اتصال داده

> نسخهٔ راهنمای موضوعی؛ کد مبنا b3f203b، بازبینی انتقال ۲۰۲۶-۱۱-۰۲. متن اولیه در [کاتالوگ منابع](../../sources/CATALOG.md) محفوظ است. دستورها برای مخزن محصول و محیط مشخص همان نسخه‌اند؛ خود مخزن اسناد اجرا نمی‌شود.


مسیر جاری: تعریف و تست فنی منبع و تگ در هاب، انتشار انتخابی برای شرکت و تخصیص تگ به ورودی ماشین در WEB. راهنمای قدم‌به‌قدم نهایی پس از پیاده‌سازی و تأیید رابط تهیه می‌شود؛ قرارداد مصوب به معنی آماده‌بودن اجرای آن نیست.

مرجع: [معماری](../../core/ARCHITECTURE.fa.md)، [وضعیت واقعی](../../STATUS.fa.md) و [قرارداد مشترک](https://github.com/hossein-aghaie/pouyeshgar-workshop/blob/19b644c791ab3c228513db3aeb6e53b3e7389bd8/packages/telemetry-contract/README.md).

فرستندهٔ آزمایشی مستقیم قدیمی WEB بازنشسته شده است. برای شبیه‌ساز آزمایشگاهی هاب، [راهنمای اجرا](../RUNBOOK.fa.md) را بخوانید. این ابزار دریافت صنعتی واقعی را اثبات نمی‌کند.

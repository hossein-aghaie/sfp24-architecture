# Research & Standards

> **Status:** فهرست تحقیق؛ ادعای بررسی نسخه جاری استانداردها نیست.

| حوزه | پرسش |
|---|---|
| ISA-95 / IEC 62264 | مرز MOM/MES و ERP و منابع عملیات |
| ISA-88 / IEC 61512 | مدل تولید بچی و Recipe |
| ISO 22400 | KPIهای تولید و تفسیر معتبر |
| ISO 55000 family | مدیریت چرخه دارایی |
| کیفیت، ایمنی، آموزش | قواعد وابسته به صنعت/مشتری/سایت |

هر تحقیق باید استاندارد/ویرایش/دامنه، منبع اولیه، تاریخ بررسی، شواهد، محدودیت و اثر روی قرارداد را ثبت کند. نام استاندارد اثبات انطباق یا الزام سراسری SFP24 نیست.

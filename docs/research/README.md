# مطالعات، مقایسه‌ها و استانداردها

اینجا مسیر پیدا کردن شواهد طراحی است: چه راه‌حل یا استانداردی بررسی شده، کجا کاربرد دارد و چه نتیجه‌ای برای محصول دارد. این پوشه برای مطالعات مشترک کل محصول و چند حوزه است؛ تمام تحقیقات ماژول‌ها در اینجا کپی نمی‌شوند.

## تحقیق مربوط به کدام بخش است؟

| دامنهٔ تحقیق | محل ثبت و دسترسی |
|---|---|
| جهت کل محصول یا مقایسهٔ بین چند حوزه | همین پوشه؛ با لینک از این فهرست و سند محصول مربوط |
| مسئلهٔ اختصاصی هسته، داده یا هاب | زیرپوشهٔ تحقیق هسته؛ فهرست و سابقه از [سوابق هسته](../core/RECORDS.md) پیدا می‌شود. اگر موضوع مشترک شد، یک منبع اصلی حفظ و از حوزه‌های دیگر لینک داده می‌شود. |
| موضوع اختصاصی یک ماژول | پوشهٔ تحقیق همان ماژول؛ از [فهرست ماژول‌ها](../modules/README.md) وارد راهنما و سوابق آن شوید. روش محاسبهٔ اثربخشی یا نیاز آزمایشگاهی را در پوشهٔ بی‌ربط آموزش ننویسید. |
| بررسی فنی اتصال میان دو بخش | در حوزهٔ مسئول بررسی، با لینک از [درخواست مربوط](../governance/REQUESTS.md) و سند ارتباطی؛ چند کپی مستقل از نتیجه ساخته نشود. |

مطالعات موجود قبلی جابه‌جا نمی‌شوند: مثلاً تحقیق تفصیلی آموزش فعلاً در همین پوشه است و از صفحهٔ آموزش لینک می‌گیرد؛ این استثنای موجود باعث نمی‌شود همهٔ مطالعات جدید اینجا ریخته شوند. [قواعد ثبت و نام‌گذاری](../governance/DOCUMENTATION-POLICY.md).

## منابع و مطالعاتی که اکنون قابل خواندن‌اند

| موضوع | سند و نوع شواهد |
|---|---|
| مقایسهٔ بستر مشترک و ماژول‌های انتخابی | [پنج نمونهٔ بازار و سؤال طراحی هرکدام](OPERATIONS-PLATFORMS.fa.md)؛ منابع رسمی، حدود بررسی و ارزیابی بازخورد خواننده |
| جایگاه محصول نسبت به سامانهٔ سازمانی | [تعریف محصول و مبنای مقایسه](../PRODUCT.fa.md#erp-position)؛ جمع‌بندی دامنهٔ فعلی با منابع اولیه |
| نمونه‌های واقعی خانواده‌های نرم‌افزار و خدمات کارکنان | [فهرست حوزه‌ها](../modules/CATALOG.fa.md)؛ منابع بازار در پایان همان سند، نه اثبات سازگاری با کد ما |
| بازار و استانداردهای آموزش | [مطالعهٔ تفصیلی آموزش](TRAINING-STANDARDS.fa.md)؛ مطالعهٔ منتقل‌شدهٔ قبلی، نه ممیزی حقوقی تازه |

## موضوعاتی که در طراحی مطرح‌اند و مطالعهٔ دقیق می‌خواهند

| حوزهٔ مرجع | سؤال طراحی |
|---|---|
| استاندارد ارتباط سازمان و عملیات صنعتی | مرز مدیریت عملیات با سامانه‌های سازمانی و تبادل منابع و برنامه |
| استانداردهای تولید بچی | مدل دستور ساخت و اجرای مراحل |
| استانداردهای شاخص تولید | تعریف معتبر شاخص، دامنه و ورودی محاسبه |
| استانداردهای مدیریت دارایی | مسئولیت‌های چرخهٔ عمر دارایی |
| کیفیت، ایمنی و آموزش | قواعد وابسته به صنعت، مشتری و محل اجرا |

نام‌های فنی مطرح‌شده در منابع پیشین شامل `ISA-95 / IEC 62264`، `ISA-88 / IEC 61512`، `ISO 22400` و خانوادهٔ `ISO 55000` هستند. این جدول فهرست موضوع مطالعه است؛ ادعای بررسی نسخهٔ جاری همهٔ استانداردها یا انطباق SFP24 نیست.

هر تحقیق باید سؤال، منبع اولیه، ویرایش، تاریخ بررسی، شواهد، محدودیت و اثر احتمالی بر تصمیم را ثبت کند. نتیجهٔ تحقیق به‌تنهایی قرارداد یا اجازهٔ پیاده‌سازی نمی‌شود.

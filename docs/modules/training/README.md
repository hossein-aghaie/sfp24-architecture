# آموزش، شایستگی و ورود کارکنان

این ماژول قرار است نیاز شایستگی فعالیت‌ها، آموزش، آزمون، ارزیابی، شواهد و Skill Gap را پوشش دهد. آموزش فقط برای اپراتور تولید نیست؛ فعالیت اداری، کیفیت، نگهداری یا ایستگاه بدون ماشین هم می‌تواند نیاز آموزش داشته باشد.

**وضعیت:** شواهد کد شاخهٔ مستقل آموزش به پیش‌نمایش تألیف مرحلهٔ سوم با JSON محلی و مجوز اختصاصی محدود است. تحویل این مرحله در کامیت `f57e23e` ثبت شده است. LMS، محاسبهٔ Gap، آزمون عملیاتی، Onboarding و AI متصل هنوز ساخته نشده‌اند. [کامیت پیش‌نمایش](https://github.com/hossein-aghaie/pouyeshgar-workshop/commit/f57e23ebe4e59c934e4c283bfa11f1fcffacb765) · [وضعیت و مرز ادغام](WORKSTREAM.md)

تأیید هدف محصول با تأیید API، schema و شروع کدنویسی یکی نیست. [مسائل مشترک باز](../../core/OPEN-QUESTIONS.md) · [صفحهٔ اول محصول](../../../README.md)

## ثبت و ادامهٔ کار این ماژول

[اتاق فکر و فهرست سوابق همین ماژول](RECORDS.md) نقطهٔ ورود ایده‌ها، گفتگوها، تحقیقات، آزمایش‌ها و درخواست‌هاست. اسناد تخصصی در همین پوشه باقی می‌مانند؛ قواعد مشترک هویت/پارامتر/مجوز فقط به [هسته](../../core/README.md) لینک می‌خورند.

برای نیاز از هسته یا ماژول دیگر، [روش و قالب درخواست](../../governance/CHANGE-WORKFLOW.md) را استفاده کنید و لینک آن را در [فهرست مشترک درخواست‌ها](../../governance/REQUESTS.md) ثبت کنید. وجود پوشه یا پیش‌نویس، اجازهٔ کدنویسی قابلیت جدید نیست.

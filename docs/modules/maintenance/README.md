# نگهداری و تعمیرات

پیگیری درخواست تعمیر، سرویس و کار تخصصی روی تجهیزات.

**وضعیت:** گردش درخواست خرابی و دستورکار در نسخهٔ پایلوت آزمایش شده است. نگهداری همچنان `pilot_only` است و قرارداد عمومی اتصال و چرخهٔ عمر ماژول هنوز نهایی نشده است. [پروندهٔ فنی پایلوت](https://github.com/hossein-aghaie/pouyeshgar-workshop/blob/627feed3f93411554be0ed0be623ec43ec1e106b/docs/development/core-module-pilot-v1/README.md)

## اطلاعات ورودی و نتیجهٔ موردنیاز

| ورودی احتمالی | نتیجهٔ احتمالی |
|---|---|
| تجهیز، گزارش خرابی، رخداد معتبر یا برنامهٔ سرویس | درخواست/دستورکار تعمیر و وضعیت رسیدگی؛ شکل دقیق هنوز طراحی نشده |

این جدول قرارداد API نیست. برای هر ورودی باید منبع معتبر، نوع، زمان، دسترسی و رفتار نبود داده تعیین شود.

## پیش‌نیاز مطالعه و اتصال

[هدف محصول](../../PRODUCT.fa.md) و [معماری](../../core/ARCHITECTURE.fa.md) را بخوانید؛ سپس [هویت و دسترسی](../../core/IDENTITY-AND-ACCESS.fa.md)، [داده و پارامتر](../../core/DATA-AND-PARAMETERS.fa.md) و [قواعد ارتباط بخش‌ها](../../contracts/README.md) را برای نیاز همین ماژول بررسی کنید. تعریف مشترک را در اینجا کپی نکنید.

نمایش فرم، کار ارجاع‌شده یا نتیجه در میز کار به [قواعد فضای کاری](../../core/WORKSPACES.fa.md) و مجوزها وابسته است؛ API عمومی یا Task Engine آماده فرض نمی‌شود. وابستگی به هر ماژول دیگر باید صریح و رفتار نبود آن مشخص باشد.

## سؤال‌های طراحی و قدم بعدی

چه کسی خرابی را اعلام و چه کسی کار را تأیید می‌کند؟ بدون تله‌متری چطور کار می‌کند؟ قطعهٔ یدکی و موجودی را خودش نگه می‌دارد یا از اتصال دیگری می‌گیرد؟

قدم بعدی، انتخاب یک سناریوی واقعی و تعیین ورودی، کاربر، نتیجه و کمبود اتصال برای همان سناریو است؛ نه پیاده‌سازی موتور از روی نام ماژول. نیاز مشترک را با [قالب درخواست](../../governance/CHANGE-WORKFLOW.md) ثبت و در [فهرست درخواست‌ها](../../governance/REQUESTS.md) لینک کنید.

## اسناد و اتاق فکر این ماژول

[سوابق و اتاق فکر](RECORDS.md) فهرست ایده، گفتگو، تحقیق، آزمایش، تصمیم و درخواست‌های همین ماژول است. نوشتهٔ جدید در پوشهٔ همین ماژول و طبق [قواعد ثبت](../../governance/DOCUMENTATION-POLICY.md) قرار می‌گیرد. [پرسش‌های مشترک هسته](../../core/OPEN-QUESTIONS.md) و [سوابق تاریخی](../../sources/CATALOG.md) منابع زمینه‌اند؛ تکمیل راهنما مجوز اجرا نیست.

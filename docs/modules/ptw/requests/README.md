# درخواست‌های PTW به هسته و دیگر ماژول‌ها

**هنوز درخواست فنی شماره‌گذاری‌شده یا پذیرفته‌شده‌ای برای PTW ثبت نشده است.** این صفحه مقصد ثبت و پیگیری نیازهاست، نه فرض وجود APIهای آماده.

موارد نیازمند بررسی در زمان طراحی: هویت و scope مجوزدهنده/ناظر/پیمانکار؛ خواندن شواهد آموزش و صلاحیت؛ ارتباط با دستورکار تعمیرات؛ ثبت و اعتبارسنجی امضا، رویداد و زمان؛ کنترل فایل/نسخهٔ روش کار؛ اعلان‌ها، تحویل شیفت و ثبت بازدیدها.

اگر کمبود مشترک با شواهد مشخص شد، یک `REQ-ptw-NNNN-topic.md` با مقصد، سناریو، ورودی/خروجی، دلیل، نسخهٔ مبنا، پاسخ، وضعیت و آزمون ایجاد کنید؛ در [فهرست درخواست‌های مشترک](../../../governance/REQUESTS.md) هم لینک دهید. [گردش تغییر](../../../governance/CHANGE-WORKFLOW.md).

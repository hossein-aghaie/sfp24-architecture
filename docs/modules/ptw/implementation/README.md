# مشخصات اجرای PTW

**هیچ تسک برنامه‌نویسی مصوب، API، migration یا موتور PTW آماده در این پوشه وجود ندارد.** این مسیر فقط برای مشخصات آزمون‌پذیر بعد از تأیید نیاز و قرارداد است.

پیش از اولین تسک: محدوده و حوزه قضایی با مسئول HSE مشخص شود؛ فرایند و وضعیت‌های مورد تأیید تعیین شود؛ مرز ماژول/هسته/آموزش/تعمیرات با قرارداد روشن گردد؛ نقش‌ها، امضاها، دادهٔ لازم و مدت نگهداری تعریف شوند؛ سناریوهای توقف، وقفه، بازگشایی، خرابی اتصال، عدم دسترسی و رخداد اضطراری با تست و روش بازگشت مشخص شوند.

**ملاک ایمنی:** وجود فرم یا امکان امضا در نرم‌افزار هرگز گواه ایمن‌بودن عملیات نیست. هیچ اجرای واقعی PTW نباید با تکیه به این پیش‌نویس بدون ارزیابی، کنترل و تأیید مسئولان صلاحیت‌دار آغاز شود.

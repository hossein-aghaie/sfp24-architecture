# آزمایش‌ها و تجربه‌های PTW

**هنوز هیچ آزمایش یا تجربهٔ آزموده‌شدهٔ PTW برای SFP24 در این پوشه ثبت نشده است.** وجود این مسیر به معنی پیاده‌سازی، آزمون با کاربران یا تأیید ایمنی نیست.

برای نخستین آزمایش از `YYYY-MM-DD-topic.md` استفاده کنید و این موارد را ثبت کنید: فرضیه، سناریوی واقعی و محدوده سایت، نسخهٔ نمونه/کد، روش و معیار پذیرش، شرکت‌کنندگان و حدود مجوز آنها، دادهٔ بدون حساسیت، مشاهدهٔ واقعی، خطا و شکست، نتیجه و تصمیم بعدی.

**نمونهٔ آزمون‌های پیشنهادی (انجام نشده):** جلوگیری از آغاز کار بدون تأیید؛ اخطار و توقف در انقضای مجوز؛ ثبت وقفه و تعلیق پس از تغییر شرایط؛ مشاهدهٔ بازدید دوساعته در سناریوی خاص شرکت بدون تعمیم آن به سایر خطرات؛ بازبینی به‌موقع ناظر؛ تطبیق مشاهده با سوابق واقعی؛ عدم افشای اطلاعات بین شرکت‌ها.

تست نرم‌افزاری هرگز جای ارزیابی میدانی متخصص ایمنی یا کنترل واقعی خطر را نمی‌گیرد.

# تصمیم‌های تخصصی PTW

**تا تاریخ ۲۰۲۶-۱۱-۰۳ تصمیم فنی یا قرارداد PTW در این پوشه تصویب نشده است.** انتخاب پوشهٔ مستندات زیر خانوادهٔ HSE، تصمیم درباره استقلال تجاری ماژول، ساختار جداول، جریان API، مسئول امضا یا انطباق حقوقی نیست.

موضوعات باز: جایگاه PTW در بستهٔ HSE؛ نقش‌ها و جدایی وظایف؛ دسته‌بندی خطر؛ نیاز به ارتباط با آموزش/تعمیرات؛ سیاست بازدید و نظارت؛ تعلیق، تمدید و بایگانی؛ مقررات حوزهٔ قضایی.

برای هر تصمیم مصوب/ردشده یک فایل تاریخ‌دار و شناسهٔ حوزه‌ای مطابق [قاعدهٔ ثبت تصمیم](../../../governance/DECISION-RECORDS.md) بسازید؛ زمینه، گزینه‌ها، دلایل انتخاب/رد، شواهد، تأیید مالک و شرایط بازنگری باید ثبت شوند.
